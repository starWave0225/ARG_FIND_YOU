# 《我要找到你》

网页 ARG 游戏原型。已将90份文档初稿和24个场景单元接入游戏：序章、远程调查、事件墙、第三章首次进村、旧案与身世核验、终审报道，以及12组可选调查和两篇番外。桌面和场景沿用中式动漫像素风；缺少成品照片、录像和音轨的材料采用文字检视版。

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器访问 `http://127.0.0.1:4173/`。

人物形象册：`http://127.0.0.1:4173/docs/character-album.html`

## 主角档案

开场随机预填一个主角姓名，玩家可修改（1—12 个字），选择男性或女性，再确认进入游戏。切换性别不会覆盖已填姓名。姓名和性别随本地存档保存，姓名用于工作台、开始菜单、首页问候、调查结论和外发回执。旧存档保留已选性别和游戏进度，尚未确认姓名的存档补一次随机姓名确认；已经确认的姓名不会重新随机。策划初稿中尚未改写的“陈默”按主角占位名理解。

## 岭川搜寻

桌面打开“岭川搜寻”，输入已设定的关键词，直接打开固定关联的文章/链接；多个关键词取交集，按类型/来源/年代筛选，查看原文与同源转载，连同出处收入案卷。已接入原16条资料/目录及90份材料、通信与番外的索引、最近搜索、来源阅读、后退前进、收藏恢复，以及从目录申请第一章索引扫描。既存文章与原始材料从开局开放；新通信、发送回执、现场借阅记录及奖励按实际发生出现。

关键词映射：`search-keywords.js`与`story-config.js`的aliases；引擎：`archive-search.js`。外部文章URL集中在`story-config.js`的external，当前均为空，页面保留不可跳转的待补链接。

## 村庄对话与档案

完成序章并接收后续消息后，打开远程资料桌：匿名投稿人补发宣传照，向盛禾申请已有索引卡扫描件，核对姓名与去向。前两章留在节目电脑，第三章才首次进村。工作台新增“调查流程”：接通学籍、退休名册、土地档案、三次后续发送、死亡时间核验与出发处理。只有完成第二章并明确出发后才开放村庄。

村庄六处NPC点击、对话、档案领取及重读代码保留在第三章入口之后。旧存档的已获材料与核验结果保留，旧版第一章进村权限不再沿用；线上副本和现场留存材料分别标来源。

NPC话题与领取条件：`village-npcs.js`；完整玩家正文：`story-documents.js`。主线和支线按材料取得、附件解锁及核验分别存档；报道完成后可继续支线。

## 正文与提示维护

修改`docs/document-drafts/`各卷“正文初稿”后，运行`python3 scripts/build-story-documents.py`生成90份玩家正文；制作备注与解法不打包。场景、谜题与链接配置在`story-config.js`，玩家阅读边界和补充检查卡在`story-flow.js`。具体映射见`docs/game-integration.md`。

不添加系统解谜提示、答案导向的建议或答错后的定向引导；提示由作者后续提供。这项约定写入`AGENTS.md`。原始文档中的字迹、日期、编号与必要操作控件保留。
