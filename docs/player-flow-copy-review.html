进村后的自由探索与恐怖交互

  1. 村口、夜巷、杂货铺、学校、祠堂外、卫生室、河桥、服务室、林场可穿插探索；先点画面中的人物，才出现对话。
  2. 宗祠供桌香炉：读纸条 → 点香观察 32 秒 → 钟响及约 8.5 秒视觉残留 → 选择观察结果 → 保存观察记录。不会自动认定面孔身份。
  3. 佛堂首次拜访：点击佛像流泪、观音睁眼。真正离开后再次进入，两尊像成为鬼佛。
  4. 井口点击木板读四句诗，祠堂观察四排五列灯笼，按亮灯位置读出“碍奇三忆”；点击鬼佛进入四手近景 → 手指组合 2731 → 中间石板开启。此处为作者答案；游戏不展示数值和解法提示。
  5. 点击开口 → 红线纸包 V03、复写本 V04、查验签 V05 → 正反面查看、分别拍摄、保存笔记；两面齐全收入案卷。
  6. 带 V03 回访盛福根；V04 回访钱素兰；V05 回访盛石生／盛禾。通过搜索收藏副本也可出示，不能据此伪造现场拍摄。
  7. 村史起点还包括盛福根的 V01 和钱素兰的 V02。求嗣、香期经营和后期旅游形成可选背景线。

实际交互边界：宗祠地板暗格现在只有检视文字，与鬼佛壁内暗格是两处物件；林场相机与磁带机目前是文字检视，录像入口提供文字轨；视觉残留仍是观察记录，不是更深一层身份解锁。
