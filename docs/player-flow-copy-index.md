## 玩家流程

既存资料从开局开放关键词检索；主线核验和发布仍按顺序进行，第三章首次进村。

- **开局｜节目电脑**：输入姓名、选择性别，随机姓名可以修改。接收匿名投稿 TG-240824-019，建立 QT-073。（身份设置、P01、P02）

- **序章｜电脑／岭川搜寻／旧厂网页**：检视旧信封 → 1993 邮政区划 → 工厂改名 → 老合影工号 → 通讯录 → 人物库与证据墙 → 确认盛德昌 → 回传资料。（P01–P08；邮编 435160，工号／通讯录密码 0717）

- **第一章｜远程资料桌**：接收旧宣传照，申请索引卡，初步核验桂枝去向为县卫校；再查学籍、校友和退休记录。核对盛广财的误录和迁出；第四次发送盛承安资料。（C1-01–C1-09；M04–M06、S04）

- **第二章｜事件墙**：匹配三条死亡新闻，排列核验、外发、事件时间；回看第四次外发，保全记录、转交异常并尝试联系盛承安。（C2-01–C2-04；M07–M09）

- **首次进村｜走访清单 → 村口**：确认未数字化原件的保管处，完成 DEPART。此后村庄在独立标签页探索，六位 NPC 可自由穿插拜访。（DEPART；非开场进村）

- **第三章｜祠堂、学校原件**：户籍 3 人与照片 4 人不符 → 照片白边与升学资料对应许行远 → 查出生与寄养关系。（C3-01–C3-05；M10–M12）

- **第四章｜林场、卫生室／档案阅读点**：查林知微失踪与举报；追流转附件；比对录像巡护牌、伤情、火灾、用车与底账，重建 1995 年事件。（C4-01–C4-11；M13–M17）

- **第五章｜历史产房档案**：盛承安出生晚于旧案；查 A/B 两个存活婴儿，发现 B 联病亡附记之后仍在医院就诊。（C5-01–C5-05；M18–M20）

- **第六章｜两日去向板、福利院、家庭相册**：追两婴去向 → 接收号 → 收养人 → 家庭生日资料；确认玩家对应 B 联，盛承安是另一个孩子。（C6-01–C6-06；M21–M24）

- **第七章｜母亲旧物与关系板**：医疗摘要限定推断；读母亲短笺，确认生父盛临川，区分生育、寄养和收养，确认许行远为亲叔叔。（C7-01–C7-03；M25–M26）

- **终审｜节目电脑**：七类证据与原件配对，读报道预览，保留未核实部分，确认游戏内发布。（E01、E02；REVIEW、PUBLISH）
