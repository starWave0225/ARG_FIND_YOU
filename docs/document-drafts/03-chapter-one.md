## 本卷场景与游玩顺序

本章全程在节目电脑：许补发照片 → 向盛禾申请独立索引扫描 → 学籍与退休名册 → 线上申请023户底册 → 象棋赛核验 → 第四名资料发送。村庄仍是反复出现的地名，没有地图、现场探索或NPC群像。

### [SC09 · 远程资料桌：隔着屏幕寻找故人](15-scene-flow.md#sc09)

画面布局：左侧“投稿消息／资料申请”，中央“照片正反面／扫描原页”，右侧“姓名与去向核验”，底部“收入案卷／来源”。剧情中的联系均由本作界面模拟，不需要外部真实通信。

第一章已接入照片副本和索引卡扫描件的接收、阅读及初步去向核验。后续学籍、名册和发送待制作。索引卡、宣传照的正式像素物证图仍须按下文埋设要求补齐；不给玩家看卫生室全景来代替远程资料。

第三章再去 [SC08卫生室](15-scene-flow.md#sc08)、[SC03杂货铺](15-scene-flow.md#sc03)、[SC04学校](15-scene-flow.md#sc04)，核对原件和先前收到的扫描件；这些现场访问不倒过来阻断本章。

## C1-01｜卫生室借用与代领索引卡

- 出现：第一章远程资料桌；通过节目资料联系渠道向盛禾申请卫生室既存扫描件。药柜12号是原保管位置，不要求玩家到场。
- 用途：由“桂枝”取得完整姓名。

### 场景与玩家流程

- **检索与来源入口**：搜索盛家村 卫生室，查看扫描目录、整理员及原保管位置，再申请对应页。接收后可在案卷材料结果中查看扫描。 参见[搜索设计](16-search-engine.md)。
- **所在画面**：[SC09 · 远程资料桌：隔着屏幕寻找故人](15-scene-flow.md#sc09)。
- **何时可见**：第一章远程资料桌；通过节目资料联系渠道向盛禾申请卫生室既存扫描件。药柜12号是原保管位置，不要求玩家到场。
- **点击位置**：远程资料桌 → 盛禾的资料联系栏 → 申请并接收索引卡扫描件。
- **操作到反馈**：比对同名简称与全名，把姓名证据放入卫生室结论槽。
- **完成后**：得到罗桂枝全名；配合背面题记解锁卫校检索。 下一步按对应场景的出口继续，也可留在案卷复看。
- **显示边界**：正文是作者全量稿；成品须按下方制作单区分初读、核验后内容，不将结论提前填入。

- **关联文档**：[N02](01-npc.md#n02)、[C1-02](03-chapter-one.md#c1-02)、[C1-03](03-chapter-one.md#c1-03)
