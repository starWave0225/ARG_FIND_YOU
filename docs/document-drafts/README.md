## 怎么修改

每份现在有“解谜元素制作单”：逐项写明必须埋入的位置和原值、关联文档、玩家操作、判定结果、待做附件与开放边界。改正文前先看制作单，避免删去解题必需的日期、图例、编号或锁外提示。制作单与备注是给作者的，不进入玩家正文；编号建议保留。

本批正文已编译为游戏内90份材料与通信。调查流程接通学籍之后至终审的主线，另接12组可选调查；缺少成品视听的物证用文字检视实现。既存材料开放搜索，附件锁保持有效，生成记录按实际进度出现，作者备注不进入玩家正文。资料形成时的人只写当时能知道的内容；后来的调查结论和作者解释分开。

## 主支线与解谜总览

主线仍是寻人、旧案与双胞胎身世的 **26 条谜题**；HM 是可选世界观支线。即使一份 H 文档都不读，也能完成主线及原有最佳结局。关联文档中出现 H 编号时，对主线只作为可选旁证，不作解锁前置。

新增 **12 组可选扩展互动**：旧图对齐、照片拼边、巡检摩斯码、比例测绘、版本来源、合同页差、时钟校正、资金对账、业务授权、声轨比对、单变量观察、停止绑定与回执复核。详见 [跨文档玩法、答案、三级提示与素材表](13-puzzle-blueprint.md)。12组互动已接入文字／点选核验原型；精细拖拽、成品图像和音轨仍按素材单完善。
