# 第三章《第四个人》文档初稿

覆盖谜题 10—12。HM 的改造资料可以解释旧文件如何被重新整理，但不得把整理员变成知晓所有血缘关系的叙述者。

## 第一次进村：开场过渡

这是玩家第一次到盛家村。第二章已经发现资料外发与死亡的关联，并回看第四次外发；节目组暂停向许继续提供资料、保全并转交记录、尝试联系盛承安。来到村里是核验投稿人身份与旧档来源，而不是又接一单普通寻人。

远程资料保管处回复：“你们问的那组家里的老照片，还没做过完整扫描。目录只能告诉你放在哪里，照片背后的字得当面核一下。”这封回复推动出发，不预告第四个人的名字和亲属答案。

落地顺序：候车亭前停留 → 看旧地名与手中资料是否对应 → 和盛福根简短交谈或直接按联络地址找盛禾 → 问到旧物保管处 → 正式打开村庄地图和本章调阅。任何一个可选N档案都不是开地图的钥匙。

第一次自由探索以“熟悉的资料终于对应到现实地点”为情绪核心。卫生室、商店和学校可核对前两章副本；祠堂内室在取得本章调阅许可后打开，林场留到第四章。
