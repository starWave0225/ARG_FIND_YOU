# 岭川搜寻：开放调查与固定关键词关联

作者审阅稿 · 2026-09-09 更新。此版取代旧稿中按章节开放搜索、先领取才能检索的规则。

## 搜索规则

玩家从建立角色后即可使用搜索引擎，不必先接投稿、完成章节或解开其他谜题。已有文章、历史档案与数字化副本始终可以通过关联关键词找到，并可阅读、查看来源、收藏和回访。搜索不是任务解锁菜单。

采用人工维护的明确关键词映射：人名、地点、机构名、原件题名、年份组合、历史户号与档案编号都可关联文章。统一全半角、大小写和空格；不做正文模糊匹配，不自动推荐关键词或解谜提示。空搜索不罗列全部资料。

## 阅读与谜题

结果卡保留标题、发布者、年份、档案号及摘要，阅读页保留原文、来源链与关联原页。玩家可以从任意文章发现新关键词，再回到搜索交叉查询。没有“必须到第三章才能阅读”的门槛。

附件原有密码仍属于谜题：搜索立即显示封面及查验入口；只要知道密码，即使开局也可打开、收藏。不能以收藏绕过密码。外部原文没有 URL 时保留无 href 的待补链接，游戏内摘录可正常阅读。

搜索、阅读、收藏不会自动生成结论、发送个人资料、出发或完成剧情节点。回执和核验结论由玩家的实际操作产生；现场对话与借阅记录在交谈后取得；两份前作番外仍是支线奖励。这些不是为了限制文章阅读而设置的章节锁。

## 匿名投稿人

开场投稿、消息和历史发送回执只使用匿名投稿人与 TG-240824-019，不直接给出姓名、年龄、所在地或亲缘结论。玩家如果自行搜索到历史档案，可以提前发现许行远这个名字；历史姓名与投稿账号的关系由玩家结合证据判断，不强制等到某一章才允许检索。

## 来源与保存

保留公开文章、私人副本、原档扫描和玩家自身记录的来源区别；可在工作站检索不代表材料曾向社会公开。转载要能回到原页，同源转载不重复算独立证据。

后退、前进、筛选、最近搜索、已读与收藏随存档保留。案卷页仅展示玩家实际收藏或取得的材料，不在开局自动摆出整套剧情档案。

实现位置：`archive-search.js`、`search-keywords.js`、`story-config.js`、`story-flow.js`。其他分章设计稿的材料顺序视为建议调查路线，不作为既存文章的搜索开放条件。
