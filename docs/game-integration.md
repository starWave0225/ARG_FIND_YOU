# 游戏内文档与场景接入

2026-09-09。当前是可贯通的剧情原型，成品图像、声音和逐帧视频继续制作。

## 入口与流程

工作台左侧“调查流程”，或第一章远程资料桌核验成功后的“继续调查”。既有序章保持原操作入口；新增流程从M04学籍开始，经过后续寻人及明确外发、第二章事件墙、异常情况处理与出发，到祠堂／林场、产房／福利院、家庭相册、母亲旧物和终审。M09结束不直接进村，必须另行点击出发。

27个新增主线步骤包含M04—M26、第四次资料发送、出发、终审与游戏内发布。原序章M01—M03保留。12组支线互动分别有前置，不影响主线。RW01与RW02独立领取，均不进入证据列表。现场6个NPC保留原有对话与借阅条件。

## 正文与原型表现

- `story-documents.js`：90份正文（含九封章节通信），由`python3 scripts/build-story-documents.py`从各卷“正文初稿”生成，排除作者制作单及备注。
- `story-config.js`：24个场景、主线／支线节点、核验字段、附件锁、关键词别名和外部链接。
- `story-flow.js`：节点开放、案卷阅读、材料领取、错误中性反馈、出发、发送快照、终审及奖励；同时包含原型的附页检查卡。
- `story-flow.css`：沿用像素桌面边框、纸张与青绿色配色。

背景使用现有村口、祠堂、卫生室、林场和夜巷像素场景。照片比对、录像片段、比例测量、声轨和时间排序以文字检查卡、表格、选项实现；它们是当前原型的等价操作，并不表示成品录像或音频已经生成。原画对照板没有冒充原始物证。

H05在玩家页拆为原稿、游客稿与审批记录；H08在玩家页拆为支付、归集和普通工资凭证。两页的初读表现、其他配套检查卡在`story-flow.js`中维护，避免作者稿中的对照答案提前展示。C6-05按原件展示收养登记内容；H14的完成回执只在实际完成后出现。

主角姓名和性别替换到正文、回执及婴儿记录。原始医疗与现场副本来源分别保留。既存原始资料的标题、正文和搜索结果不按阶段限制，附件码查验不能被收藏绕过。

## 外部链接

`story-config.js`的`external`集中保存需要补充原文的条目。当前URL全为空，页面显示“外部原文链接（待补）”，不生成href、不打开空页面、不编造真实网址。游戏内正文摘录继续可读，空链接不阻断核验。

填写真实链接后，阅读页将提供新标签页原文入口。配置只接受http/https地址。

## 提示约定

游戏页面不新增提示按钮、提示折叠区、答案建议或失败后指出正确字段的引导。答错显示中性结果。原始材料中已经存在的文字、时间、编号与物件题字保留；提示文案由作者后续提供。项目根目录`AGENTS.md`记录此约定。

## 验证

`npm test`同时加载游戏实际脚本，覆盖原有交互、新开场、自定义姓名、全主线贯通、两条支线独立奖励、借阅条件、完整发送快照、存档恢复、附件锁和后期内容隔离。DOM测试不覆盖真实浏览器布局及原生对话框焦点。

## 投稿人身份显示

开场至第二章以“匿名投稿人 / TG-240824-019”识别联系方，投稿、附件、搜索来源、发送确认和历史回执不显示真实姓名、年龄及所在地。M08核验共同接收账号。玩家可随时自行搜索旧照与学籍发现许行远姓名，亲缘身份继续分阶段查证。旧存档的外发快照展示同一账号，不提前透出旧版姓名。

## 开放搜索（2026-09-09 更新）

已有文章、历史原件和数字化副本可从开局按明确关键词搜索、阅读及收藏，不要求先接投稿、完成章节或领取其他线索。已补充姓名、地点、机构、历史户号与档案编号关联。附件密码是原件谜题，不依赖章节进度，可提前解开。搜索不会自动核验、发送、出发或领取奖励。

投稿和历史发送保持匿名账号称呼；隐藏身份通过开场不主动透露实现，不再屏蔽玩家主动检索的历史姓名。个人操作产生的回执、结论和现场借阅记录在实际产生后收入案卷，前作奖励仍由支线领取。案卷列表只显示已收藏或实际取得的记录，不在开局铺开所有文章。

## 盛家村独立页面

进入村庄改为新标签页 `?view=village`，现场画面填满浏览器页面，不显示桌面任务栏及村庄窗口标题栏。`scene` 参数可直达具体地点；地图、人物对话与借阅沿用已有进度。同源标签页监听存档变更，同步姓名、线索、NPC档案和剧情节点。

## 场景探索与恐怖效果

进村默认先看到旧邮亭场景中的盛福根；点击人物才进入底部对话。地图可走入村口暮色、中央夜巷、卫生室正常／异常状态、宗祠内景及林场火场遗址。宗祠连接旧佛堂，佛像流泪和观音睁眼为可重复观察的动画。宗祠香炉接回既有视觉残留谜题，32 秒注视及 8.5 秒余像后记录所见，生成单独观察档案，不自动推断人物身份。设计、素材和生成提示词见 `docs/shrine-afterimage-effects.md`。

旧佛堂重访状态：首次进入为正常双像，离开再回来换为两尊鬼佛，并持久保存。刷新、案卷与存档同步不触发变异；不产生主线进度或新增提示。详情见 `shrine-afterimage-effects.md`。

村史 V01／V02 由 `17-village-faith.md` 编译：旧邮亭与杂货铺新话题提供阅读入口，原件可按明确关键词自由检索；三位 NPC 的口述、H02／H04 背景及人物设定同步。只增加自选材料，未添加主线判题或改变鬼佛触发。34 项回归通过。

`ghost-hands.js` 接入鬼佛点击近景和四手 2731 机关，控制20根石指及两像中央暗格，操作进度持久保存。36项回归通过；不新增主线解锁条件，作者设计记录见 `ghost-hands-puzzle.md`。
