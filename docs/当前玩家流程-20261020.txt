《我要找到你》当前玩家流程
作者审阅版｜2026年10月20日｜含完整剧透

本文件记录当前实现中的玩家流程，供本地审阅与修改。
完整故事另见 docs/story-master/revised.md；本文不把母本中的待做情节算作已经可玩。
这是独立审阅快照，不参与玩家正文编译，也不会出现在游戏搜索结果中。

一、当前可完成的路线

接收匿名投稿 → 找到并发送四人的资料 → 发现死亡关联 → 保全与转交异常 → 确认进村 → 调查旧案 → 核对双胞胎与收养身份 → 确认生父和叔侄关系 → 七类证据终审 → 游戏内发布报道。

当前走通的是调查、核验与报道发布流程。许行远追踪玩家、末段威胁、追杀和叔侄现场对峙尚未完整接入。

二、按章节的实际游玩顺序

【开局｜节目电脑】
玩家操作：
1. 输入或修改主角姓名，选择男性或女性，确认进入游戏。
2. 接收匿名投稿 TG-240824-019，建立选题 QT-073。
3. 阅读“寻找多年未见的故人”的委托，打开旧信封附件。

剧情所得：
玩家是寻人节目的策划。主动开场只展示匿名投稿人与联系账号，不提前揭露许行远姓名及亲缘。

【序章｜寻找盛德昌】
玩家操作：
1. 检视信封上的旧单位名称与残缺邮编。
2. 检索1993年邮政区划，确认旧厂所属地区。
3. 查东岚农机厂沿革，接上改名后的东岚机电二厂。
4. 检视维修二组合影，读取工号，打开对应通讯册。
5. 对照人物库中的单位经历、工号和调动去向，提交身份核验。
6. 通过游戏内电话联系并确认盛德昌，预览外发内容，亲手确认发送。

剧情所得：
找到第一位“故人”，形成核验结论与不可撤回的发送回执。
相关材料：P01—P08。

【第一章｜远程资料桌】
玩家操作：
1. 接收匿名投稿人补发的妇幼宣传照正反面。
2. 向盛禾申请卫生室既存索引卡扫描件，交叉核对“桂枝”的完整姓名及卫校去向。
3. 查卫校学籍，区分照片拍摄年与入学年，确认罗桂枝。
4. 查校友、任职、岭川县医院荣誉退休简讯和志愿服务记录，核验后确认发送罗桂枝资料。
5. 按旧户号追查盛广财的迁出记录，区分报名名单中的姓名误录与同名者，核验并确认发送。
6. 阅读匿名投稿人补充的盛承安人物页，预览住址及联系电话范围，确认第四次发送。

剧情所得：
完成其余三次外发。医院先作为罗桂枝工作与荣誉退休的来源出现，为后续出生记录调查建立联系。
相关节点：M04—M06、S04；此前还有远程索引卡与照片的初步核验。
相关材料：C1-01—C1-10。
此阶段仍在节目电脑前，尚未进入盛家村。

【第二章｜事件墙】
玩家操作：
1. 用年龄、地区与职业，为三条死亡简讯分别配对人物。
2. 排列九张核验、外发与事件时间卡。
3. 计算三次发送到对应事件的间隔，核对共同接收账号。
4. 回看第四次发送，确认盛承安资料已经送达及当时的发送范围。
5. 暂停新增个人资料外发，保全原投稿、聊天和四次发送记录。
6. 在游戏内转交异常情况及第四名对象信息，并通过已核验渠道尝试联系盛承安。

剧情所得：
三名死者对应已经找到的三个人。外发分别早于事件约31、22、27小时，第四份资料无法撤回。
相关节点：M07—M09。
相关材料：C2-01—C2-04、P08。

【出发｜首次进入盛家村】
玩家操作：
1. 接收原件保管处回复，登记未完整数字化的家庭旧照与历史户籍原页。
2. 确认异常外发记录已经保全并转交。
3. 明确选择“前往盛家村”。

剧情所得：
抵达村口，开放村庄地图和六位村民的场景探索。此后可以穿插走访。
相关节点：DEPART。
开局及远程调查阶段不显示盛家村快捷入口。

【第三章｜照片里的第四个人】
玩家操作：
1. 比较三人户籍与四人家庭照，暂不把人数差直接当作亲缘证明。
2. 结合照片年份、年龄、白边题记和升学资料，对应许行远。
3. 解锁人口清查附页，区分实际血缘、寄养与户籍登记。

剧情所得：
许行远是盛长林与周淑琴的亲生次子、盛临川的弟弟，自幼寄养许家，户籍随许。
相关节点：M10—M12。
相关材料：C3-01—C3-05。

【第四章｜火以前发生了什么】
玩家操作：
1. 对照失踪登记与村内旧册，查清林知微原来的身份及登记缺口。
2. 调阅举报与流转附件，核对盛守平调阅、盛守安接收及附件缺页。
3. 比对历史录像中的巡护牌、画外喊声与领用记录，确认盛临川。
4. 比较伤情留存笔记和专业复核，区分火前伤、热损伤及无法判断项。
5. 将用车登记、伤情、私人底账与火灾存档合并核验，重建事件先后。

剧情所得：
林知微被拐卖和限制自由；举报回流村内；盛临川火前遭受暴力并被转运；“电路故障”的旧结论存在无法解释的内容及掩盖线索。
相关节点：M13—M17。
相关材料：C4-01—C4-11。
完成M13后，可以另走X13，追查林知微与教会旧卷。

【第五章｜两个存活的新生儿】
玩家操作：
1. 阅读盛承安身份与事件核查回复，把他的出生时间放在1995年旧案之后。
2. 调阅产房索引，解锁新生儿观察两联，比较编号、出生时刻和存活情况。
3. 按同一医疗编号核对村内病亡附记与县医院实际就诊记录。

剧情所得：
盛承安已经死亡，且旧案发生时尚未出生。林知微生下两个存活的孩子，B联被记作病亡后仍于医院就诊。
相关节点：M18—M20。
相关材料：C5-01—C5-05。

【第六章｜无名婴儿与玩家自己】
玩家操作：
1. 重建7月29日、30日两名孩子和林知微的位置及去向。
2. 将县医院识别副签与福利院接收号对应，区分编号证据和毯纹特征。
3. 追查临时照看及收养移交，阅读家人提供的照片背面，补全收养人姓名。
4. 对照医疗、接收、收养和玩家家庭资料，提交身份核验。

剧情所得：
B联孩子于7月29日经县医院进入福利机构，林知微于次日独自返村。收养人是陈建平、沈芸，玩家就是B联孩子，盛承安是另一个孩子。
相关节点：M21—M24。
相关材料：C6-01—C6-06，并回查C5系列。

【第七章｜母亲留下的话与最终关系】
玩家操作：
1. 阅读盛雄历史医疗摘要，确认摘要不能独自排除具体亲子关系。
2. 按母亲旧物的锁外题字解锁短笺，保留盛承安生前上传的来源及回执。
3. 阅读林知微对两个孩子生父的指认。
4. 区分生育、寄养、收养，提交完整亲缘核验。

剧情所得：
盛临川是两个孩子的生父，许行远是亲叔叔。林知微曾把小的孩子送走，返村寻找留下来的哥哥。
相关节点：M25—M26。
相关材料：C7-01—C7-03，并回查出生、收养和许行远亲缘附页。
完成M25及X13后，可以另走X14，继续追查行愿、续问与留置。

【终审｜让记录被看见】
玩家操作：
1. 为七类证明事项匹配可追溯的主案原始材料。
2. 阅读《盛家村旧案中被抹去的人》报道预览。
3. 确认保留原始出处与冲突版本，遮盖不应公开的个人信息，区分事实与未核实责任。
4. 明确确认在游戏内发布报道。

剧情所得：
报道留档，被抹去的人重新留下姓名和经历，未核实责任继续调查。发布后可以继续村庄探索、可选调查和已解锁番外。
相关节点：REVIEW、PUBLISH。
相关材料：E01、E02；发布后出现J09收尾。
当前终审以前没有完整的追杀与叔侄现场对峙段落。

三、村庄探索方式

每个地点先展示环境远景，人物只占场景的一部分；点击人物才进入放大对话，关闭后回到同一场景。

六位村民各自提供局部资料：
1. 盛福根：旧邮路与投递路线。
2. 钱素兰：杂货铺账页、卫生室代领及香期生意。
3. 邱映秋：学校相册、底片与照片出处。
4. 盛石生：石阶、门框和修缮记录。
5. 盛禾：原件目录、资料来源及扫描交接。
6. 何小满：当日通行路线与村中道路。

不是每份后期材料都有独立的现场画面。部分历史照片、录像、声音仍通过文字检视、表格和文字声轨呈现。

四、14组可选调查

所有X系列核验均在确认进村后开放各自条件，不计入主线终审门槛。
既存原始材料仍可提前检索；支线核验是否开放与材料是否能搜索是两回事。

X01｜旧邮路与当日路线
操作：对照N01与N06，核对固定地标、旧称和当天封路。
所得：旧路与现行路线的差异。

X02｜被裁去的白边
开放条件：完成M11。
操作：按馆藏号比较原图与裁图，核对拼接锚点。
所得：照片白边姓名被裁去的来源关系。

X03｜巡检频道
操作：阅读H01静态点划记录与数字表，译读频道索引。
所得：后续声轨调查所需的索引。

X04｜附房在哪里
操作：对齐实测图与游客图的固定点，核对外轮廓、已解释空间与墙厚。
所得：游客图遗漏E-2东侧附房，不能用普通墙厚解释。

X05｜谁改写了村史
开放条件：完成M13。
操作：比较原稿、游客稿、修缮记录和审批页。
所得：照片裁名、封门年份改写、失踪与村内登记矛盾被移出游客线，以及运营验收关系。

X06｜多出来的一页
操作：比较物主联与扫描联，核对特殊保管新增页和交接标签。
所得：未经物主签收的保管页，及W-17、BG-017、R-17的链条。

X07｜三分钟误差
操作：以同次铃响校准日志时钟，再比较回应与演员离场时间。
所得：回应发生在演员离场之后。

X08｜同一批次的三笔款
操作：按批次和交易号对账，剔除普通工资。
所得：专项归集凭证、款项及接收主体。

X09｜更换招牌以后
开放条件：完成X08。
操作：核对主体全名、授权范围、冻结旧委托与运营接续清单。
所得：前台换名后仍延续的附房保管及终端业务；HM缩写不能证明同一法人。

X10｜原声中的一句话
开放条件：完成X03、X07。
操作：对齐同一时码的原始与公开文字声轨。
所得：房内原始回应“我不是来接客的”被剪去。

X11｜只改变一个条件
开放条件：完成X10。
操作：比较既往观察卡中的单变量变化，不执行新实验。
所得：称谓、物品等条件与回应存在关联，但R-17身份尚未证明。

X12｜停止岗位，保留这个人
开放条件：完成X06、X11。
操作：核对R-17目标链，建立独立副本，停止强制绑定，取消自动续建，保留原物和关系记录，并核对下一批。
所得：停止回执；下一批未创建新角色，不代填消散或转生结论。

X13｜第六席留下的署名
开放条件：完成M13。
操作：由C4-01数字整理附签进入教会同卷，阅读原愿、范围附页、C行愿记与D回访夹页。
所得：林知微亲自行愿，目标为盛雄，并拒绝代受；2026年入簿日期不等于仪式原件日期，回访转述不能确认盛雄死因。

X14｜愿了，为什么还不放行
开放条件：完成M25、X13。
操作：将母亲私人短札的LZW-019与行愿记、恒目旧卷移交联及续问记录对应。
所得：私人短札与行愿记共同确认她实际实施过咒杀；所愿终结不自动等于放行。不能据移交单认定续问声音就是林知微。

五、独立探索与网站

1. 井内木板、祠堂灯阵与鬼佛四手机关已经存在。鬼佛壁内暗格可以开启取档；宗祠地板暗格目前只有检视。均不作为主线发布门槛。
2. 村庄另有修堂、求嗣、香期经营及旧物等原始材料和人物话题，可自由阅读，不自动完成主线或HM核验。
3. 教会官网提供独立栏目与愿簿档案。初次图片中的人物背向玩家，查看有效愿簿记录后出现转身、白眼朝向的变化。异象不自动证明身份、死因或完成核验。
4. 医院官网已经承担罗桂枝任职荣休、历史出生与就医记录的来源入口；主线通过编号和档案核验推进。

六、两篇番外的解锁

RW01｜《周明川日记·其五：不在这栋楼里》
条件：完成X05、X08、X09。
内容：从版本改写、资金与授权关系，连接另一处恒目项目的余响。

RW02｜《顾盼的残念》
条件：完成X10、X11、X12。
内容：与原始回应、自我意愿及停止强制角色相关的前作番外。

两篇独立解锁、互不作为前置。番外不是本案口供，不把R-17直接认定为其中人物，也不要求前作存档。

七、当前尚未完整接入及存在冲突的内容

1. 许行远独立追踪玩家的具体证据、认出B联孩子、发出“我要找到你”的威胁、追杀及叔侄现场对峙，尚未完整接入。完整母本保留这些情节，当前实际流程在关系核验后进入终审。
2. 盛承安通信仍有旧稿冲突：J05、J07像实时回复，J09还有输入状态，与母本及C5-01确定的死亡口径不一致。应改为带原时戳的生前留言、历史上传回执或由他人转交的材料。
3. 《第六席》已有独立录像，尚未完整接成正式调查中的取得与播放链；不能默认玩家就是录像拍摄者。
4. 周明川第一人称演出是独立Demo；《嫁》完美结局影片入口仍待定。它们不属于当前主线必经流程。
5. 部分视听材料使用文字检视，部分场景单元尚无独立成品画面。
6. 八个外部原文URL仍待提供，对应P03、P04、P05、C1-04、C1-07、C2-01、C3-04、C6-03。当前可以阅读内置摘录，待补链接不跳转。

八、流程与证据边界

1. 既存文章和原始档案从开局开放明确关键词检索，不按章节或收集进度屏蔽；未发生的通信、回执和奖励不能冒充历史文章。
2. 搜索、阅读及自动留存不等于理解、核验或发送。发送仍须玩家明确确认，附件自身密码保留。
3. 打开游戏内材料会连同来源自动留存；游戏外阅读不能成为可追踪前置。
4. HM、教会、鬼佛和两篇番外均不阻断原主线终审与报道发布。
5. 已确认林知微实施过针对盛雄的咒杀，并拒绝让孩子和无关者代受；盛雄死因、林知微当前生死、续问声音身份和放行结果仍保留疑云。
6. 当前“可以通关”指调查与报道发布路线，不代表完整母本的追杀高潮已经全部实现。
