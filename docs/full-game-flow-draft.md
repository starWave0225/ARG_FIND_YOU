## 玩家路线

创建姓名与性别 → 接受匿名投稿 → 旧信封、邮政区划、工厂与通讯录 → 盛德昌身份核验及首次回传 → 远程宣传照与索引扫描 → 学籍、退休、迁出记录及后续外发 → 死亡新闻与异常事件墙 → 明确出发，第一次进村 → 户籍、家庭旧照与许行远记录 → 林知微旧案 → 双婴记录 → 接收、寄养与收养档案 → 玩家身世及盛临川关系 → 终审 → 发布报道 → 留档收尾。

既存文章从开局开放明确关键词检索；主线核验按原有顺序提交。阅读和收藏不自动替玩家解题。前两章主动叙述保留匿名投稿人账号；提前搜索历史姓名不等于证明亲缘。

进村后，场景卡的“进入现场”另开村庄标签页。玩家先在环境中点击人物再对话；现场“调查记录”可回到案卷与核验。玩家也可继续用地图自由走访。
