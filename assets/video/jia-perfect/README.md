# 爱可以 找到完美的时间线

《嫁》联动完美结局，依据用户修订的十二镜头制作。刘涵沿用原男性形象；获救与医院重逢采用顾盼第一人称。结尾保留用户指定文字：“谢谢你的坚持，让故事走向完美”。

成片：`love-perfect-timeline-v1.mp4`。预览：`preview.html`。179 秒，1280×720，24 fps，H.264/AAC。像素插画以缓慢运镜、叠化与时间轴字幕剪辑成片；对白只用字幕，人物配音已按用户要求全部移除，保留背景音乐与环境音。人物动作通过关键帧切换呈现，未使用连续人物动作生成模型。

## 人物与画作

参考《嫁》的 `public/characters/gu-pan.png`、`shen-wang.png`、`liu-han.png`、`gu-jianguo.png`、`zhou-xiulan.png`，以及第三结局的像素场景。用户确认刘涵沿用原形象；后续明确要求两名男角色区分并减少正脸，最终镜头使用刘涵背影／侧脸、橄榄绿夹克与蓬乱头发，沈望深灰衣着、较整齐短发与侧向视线。绘制参考不改动原游戏立绘。

《向阳处》参考原作 `ARG_invitation/public/paintings/xiangyangchu.png`，通过内置 imagegen 定向编辑，保留旧屋、椅子、围巾、窄窗、桌子与罐中植物。新版增加明亮暖光与伸出窗台的花，保存为独立版本，没有覆盖原画。完整生成和编辑提示词见 `prompts.json` 与 `character-edits.json`；源 PNG 与已合成对白保存在 `source/`，未采用的初版亦留存供对照。医院采用 `hospital-side-v1.png` 与 `hospital-distinct-v1.png` 两张图：先以侧脸和握手为中心，再叠化到沈望望向顾盼。两张均使用缓慢运镜，保留顾盼第一视角。

## 剧情与接入

本段是由跨作电话抵达的完美时间线：救援发生在 2025 年，次年 2026 年完婚。它不将原《嫁》第三结局中的已确认死亡倒写为同一案卷中的获救，也不将本作 2026 年主线调查与救援日期混成一条普通通话时间线。跨时间线的电话机制仍交由本作剧情后续展开。

《我要找到你》在主线报道发布后，于“番外阅读”提供入口；不要求完成 HM 调查，不增加主线答案或核验门槛。既存原始材料仍可自由搜索；本视频按联动番外呈现，不冒充普通既存新闻或生成警方结论。点击播放器中的“拨通刘涵的电话”开始影片。看完仅留下独立本机阅览标记，不推进主线、不修改任何原件。

影片只接入《我要找到你》项目。《嫁》项目提供原人物形象、画作与第三结局风格参考，不添加视频页或修改其结局入口。

## 重建

需要 ffmpeg、numpy，macOS 的宋体或 PingFang 字体；其他平台可在脚本中更换字体路径。临时渲染文件写入 `/tmp/jia-film-work`，不覆盖源图。

```sh
python scripts/video/build-jia-perfect.py --stage picture
python /Users/qujunjie/.codex/skills/video-voiceover/scripts/extract_frames.py /tmp/jia-film-work/picture.mp4 --workdir /tmp/jia-film-work/review
# 阅读抽帧以后，合成背景音乐、环境音和用户指定对白字幕：
python scripts/video/build-jia-perfect.py --stage audio
```

`dialogue.json` 保留用户对白和字幕时码。早期配音版本曾按 video-voiceover 流程制作；用户试听后要求去掉配音，当前脚本不生成、不读取、不混入人声，原始配音素材仅在制作目录保留。所有对白以字幕出现，医院重逢不增加顾盼对白。配乐、电话铃、脚步、破门、纸张和快门由脚本原创合成。新成片先渲染到临时文件，再替换预览用的视频，避免编码过程中播放器读取半成品。
